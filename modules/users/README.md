# Users Module

## Overview

The Users Module provides comprehensive user management capabilities for the AI Banking GRC Platform, supporting user CRUD operations, role management, permissions, and profile management.

## Features

### User Management
- Create, edit, delete users
- User status management
- Department assignment
- Profile management
- Password management

### Role Management
- Predefined roles
- Role-based permissions
- Role assignment
- Role levels### Security
- Password policies
- Account lockout
- Session management
- Activity logging

### Profile
- Personal information
- Profile image upload
- Password change
- Contact details

### Activity Logging
- User activity tracking
- Audit trail
- Login history
- Action logging

## Roles

| Role | Level | Description |
|------|-------|-------------|
| Super Admin | 10 | Full system access |
| Admin | 8 | Administrative access |
| Compliance Officer | 6 | Compliance management |
| Risk Manager | 6 | Risk management |
| Internal Auditor | 5 | Audit management |
| Department Head | 4 | Department management |
| Standard User | 2 | Basic access |
