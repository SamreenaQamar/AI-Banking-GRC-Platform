# Settings Module

## Overview

The Settings Module provides comprehensive system configuration management for the AI Banking GRC Platform, supporting various sections including general, company, security, email, API, backup, AI, and notification settings.

## Features

### General Settings
- Application name and version
- Timezone and locale
- Maintenance mode

### Company Settings
- Company profile
- Branding (logo)
- Contact information

### Security Settings
- Session management
- Password policies
- Two-factor authentication
- Remember me settings

### Email Settings
- SMTP configuration
- Email templates
- From address management

### API Settings
- API enable/disable
- Rate limiting
- Version management

### Backup Settings
- Scheduled backups
- Manual backups
- Restore functionality
- Retention management

### AI Settings
- AI provider configuration
- Model selection
- API key management
- Token limits

### Notification Settings
- Channel enable/disable
- Retention policies
- Priority configuration
