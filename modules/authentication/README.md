# Authentication Module - AI Banking GRC Platform

## Module Overview

The Authentication Module provides enterprise-grade authentication and authorization services for the AI Banking GRC Platform. It handles all user authentication-related operations including login, registration, password management, and session security.

### Key Features

- **Secure Authentication**: Password hashing with bcrypt, CSRF protection, session security
- **Role-Based Access**: Automatic redirection based on user roles
- **Password Management**: Reset, change, and recovery functionality
- **Two-Factor Authentication**: TOTP-based 2FA support
- **Remember Me**: Persistent login sessions
- **Account Security**: Rate limiting, lockout, failed attempt tracking
- **Email Verification**: Verification links for new registrations
- **Session Management**: Secure session handling with regeneration
